# Customer Churn Data Science Project

## Overview

This repository contains my data science internship project focused on
developing a Python-based approach for predicting customer churn.

The project covers the complete data science workflow, including problem
definition, data preparation, exploratory data analysis, machine learning,
model evaluation, and reporting.

## Project Objectives

- Define the customer churn prediction problem
- Plan data collection and preparation
- Perform exploratory data analysis
- Develop machine learning models
- Evaluate model performance
- Generate useful business insights

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Git and GitHub
